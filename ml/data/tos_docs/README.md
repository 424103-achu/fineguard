# Collected ToS documents

Put one plain-text file per service here (for example `example_service.txt`),
and add a row for it to `../tosdr_grades.csv`:

| column | meaning |
|---|---|
| `service` | service name |
| `file` | file name in this folder |
| `tosdr_grade` | ToS;DR grade, A–E |
| `grade_date` | date you read the ToS;DR grade |
| `collected_date` | date you saved the terms |
| `url` | where the terms were taken from |

Check ToS;DR's terms of use before reusing their grades.
